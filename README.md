### Payment Gateway Project

Developed a secure online payment gateway application using **Java, SQL, and JavaScript** to simulate and manage digital payment transactions. The project handles payment initiation, transaction validation, transaction status, refunds, and transaction history. Implemented database integration using SQL for storing transaction records and JavaScript for the frontend user interface and payment interactions.

**Key Features:**

* Payment initiation and transaction processing
* Credit/debit card payment simulation
* Transaction validation and status tracking
* Refund and transaction-history management
* SQL database integration for transaction records
* Java-based backend business logic
* JavaScript-based frontend interface
* Basic authentication and input validation
* Designed with secure transaction-handling practices

**Technologies Used:** Java, SQL/MySQL, JavaScript, HTML, CSS
